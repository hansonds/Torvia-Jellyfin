🔑 TorBox connection

🔄 Sync

How often Torvia checks TorBox for new and removed titles.

▶️ Playback

Video goes from TorBox to the app, not through this server.
Apps open the TorBox link themselves.
Your TorBox CDN setting must be on Auto.
Leave empty unless videos don't start behind a reverse proxy.

🗂️ What to include

Which TorBox downloads become library items.
Each tag (e.g. movies, cinema, tv-shows) can be its own library. Keep movies and series in different tags.

Use the same tags as your library folders.
Comma separated, e.g. movies, tv-shows, cinema.

Admins can always use it, with no daily limit.
0 = no limit. Resets at midnight in the time zone set on the first tab.
